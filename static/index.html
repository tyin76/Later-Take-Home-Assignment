FOR ANDY

Connect your automations

Use an HTTP request step in Zapier, Make, n8n, or Gumloop whenever a trigger fires.

01

Choose the task

Open a project and click Copy automation URL below the task. Paste that URL into the HTTP request action in Zapier, Make, n8n, or Gumloop. Copy curl test provides a runnable Terminal check.

02

Set the request

Use method POST, header Content-Type: application/json, and this JSON body:

{"flag":"yes"}
03

Optional local name lookup

Local automations can send exact project and task names to . Repeated events return already_complete: true. Cloud tools need a tunnel for this optional local endpoint.

Talk to your projects

The included MCP server gives an LLM five focused tools. Add it to an MCP-capable chat client, then ask for updates or changes in plain language.

✳

Tools available

list_projects, get_project, list_overdue, add_todo, and mark_todo.

⌘
